# Aventureiro Pedagógico

Protótipo inicial de uma plataforma educacional gamificada em pixel art.

## Rodar localmente

1. Instale Node.js 20+.
2. Abra o terminal nesta pasta.
3. Execute:

```bash
npm install
npm run dev
```

4. Abra http://localhost:3000
